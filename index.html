Notebook Cell 11

Word-level fixation heatmap

Cumulative dwell time for each word of the passage. Darker colors indicate longer total fixation time. This is a word-level dwell-time heatmap, not pixel-level density. Hover a word for its dwell time and fixation count.

Notebook Cell 12

Fixation scanpath

The spatial and temporal sequence of fixations. Blue lines show transitions between fixations, and larger circles represent longer fixation durations. Hover a circle for the fixation index, duration, and word.

Notebook Cells 13–14

Eye-movement scanpath replay

Reconstructs the reading process fixation by fixation. Playback follows fixation order rather than real elapsed time. The red circle highlights the current fixation.

Notebook Cells 15–19

Reading conditions across all participants

Descriptive summaries from all participants. Use the filters to narrow the comparison. “All” includes every level of a condition. Text difficulty: Adv = Advanced, Ele = Elementary.

About this prototype

Source notebook

All data loading, processing, and charts come from Mia Davis's Observable notebook @miadavis/untitled/4 (version 213). The page imports the published notebook with the Observable Runtime and places each cell's output into the layout. The cell code runs unchanged.

Module source: loading…

Data

The data files are the notebook's own attachments, served by Observable:

  • onestop_trial_catalog_full.csv: one row per reading trial
  • onestop_condition_summary_full.csv: condition-level means and accuracy
  • onestop_reader_index_full.csv: participant → ZIP shard lookup
  • onestop_reader_shard_00–11.zip: per-participant fixations and word areas

Participant selector

In the published notebook, Cell 4 (“Select a Participant from the Full Dataset”) is empty, so fullReader is undefined and the per-reader cells show RuntimeError: fullReader is not defined. This site adds that single cell as a dropdown of every participant_id in the reader index. It is only added if the notebook doesn't define fullReader itself.
